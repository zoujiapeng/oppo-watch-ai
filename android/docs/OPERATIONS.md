# 操作说明（球的全部手势 / 状态 / 开关 / 调试口子）

> 面向使用者和下一个接手的人。**每一条都对着代码核实过**，不是凭印象写的。
> 对应版本：`approval-orb-4` 分支上的原生富文本版本（2026-10-16）。

---

## 一、球上的手势（在**球身上**操作，不是屏幕别处）

| 手势 | 行为 | 代码依据 |
|---|---|---|
| **双击** | 开始说话；再双击 = 结束并发送（录音中双击） | `ACTION_UP` 里 `now - lastTapAt < 340ms` → `SiriAssistant.toggle()` |
| **单击** | **什么都不做**（避免误触） | 同上，只记 `lastTapAt` |
| **长按 480ms** | 取消当前这一轮（录音中 / 正在问答时），带一次 35ms 振动 | `longPress` Runnable → `cancelByGesture()` |
| **按住拖动（>10dp）** | 只移动球，不做任何操作（松手停在原地，成为新的"家"） | `ACTION_MOVE` → `moveBallDrag()` |
| **双指长按 520ms**（任意两根手指按住不动） | **唤起搜索胶囊**：球缩成小黑球 →「一团黑」弹成胶囊 → 🔍 输入框 🎤 凝聚出现（带一次 30ms 振动） | `ACTION_POINTER_DOWN` 起 `twoFingerHold` → `enterSearchMode("双指长按")` |
| **双指拖动**（>12dp） | **回到初始圆球**，并清空所有文字 | `ACTION_MOVE` 双指分支 → `forceHomeShape("双指拖动")` |
| **双指快速点一下**（没动、也没按够 520ms） | 同"双指拖动"：回到初始圆球（老手感不变） | `ACTION_POINTER_UP` → `forceHomeShape("双指手势")` |
| **在球内文字区上下滑** | 翻阅长回复（只有"内容超出视口"时文字层才吃触摸） | `syncSiriTouchLayer()` + `ScrollView` |
| **滑动期间** | 球**保持方形不收**；松手 **1.5 秒**后恢复自动收起 | `MD_SCROLL_HOLD_MS = 1500` |
| **点球内文字** | 文字层"装得下"时不拦截 → 等于点在球上（可拖球/双击说话）；**装不下时**才吃触摸用于滚动 | 同上 |

> ⚠️ 审批面板挂着时，球本身**不抢手势**（那一片屏幕归面板用）。

## 二、状态与球里显示什么

| 状态 | 触发 | 球里显示 |
|---|---|---|
| **IDLE** | 空闲 | 初始水晶球（**不允许有任何文字/内容**）；若没字，按你的 Siri 模式设定出波 |
| **LISTENING** | 双击开始说话 | 圆球 + **Siri 波**（跟着你的音量呼吸） |
| **TRANSCRIBING** | 说完、正在转写 | 同上（波） |
| **THINKING** | DSH 思考 / 读取 / 运行命令 / 工具调用（**这四个是同一个状态**） | 有字：**上面文字 + 底部动效带里的流体圆点**；没字：**圆点铺在球心**（正常大小） |
| **ANSWERING** | 正在打字输出回答 | 文字 + **Siri 波共存**（球底那道波） |
| **最终回复结束** | `turn/end` 或本轮流收完 | 安静 **1.5 秒** → **先隐藏所有文字** → 再缩回初始圆球 |

关键规则（都是你明确要求过的）：

1. **圆球（初始形状）状态下不出现任何文字/页面**。
2. **只有最终回复才收回初始形状** —— 处理中的短回复、多步工具调用之间一律保持方形，处理中动画就在方形里。
3. 收回前**必须先隐藏所有会显示文字的东西**（内容列清空 + 视图 GONE + 触摸关闭 + 指纹清空，一次做完）。
4. 球高上限 = **屏高 55%**；宽度固定 = **屏宽 78%**；内容超出在**球内滚动**（像记事本）。
5. 球底不越过屏高 **66%** 安全线（不压你的输入框/键盘）。

## 三、审批 / 提问面板

DSH 请求批准或提问时，同一颗球展开成一张玻璃卡片：

| 元素 | 说明 |
|---|---|
| 标题 + 说明 | DSH 给的原文 |
| 选项按钮 | 审批固定「批准 / 拒绝」；提问按 DSH 给的条数与文案，**支持多选** |
| 自由输入框 | 选项都不合适就自己写（协议里的 `custom`）；单选时与选项互斥 |
| 「发送」 | 提交自由输入 |
| 答完 | 面板收回，原球状态一点不动；**谁先答谁算**（你在浏览器答了，球会自己收回） |

- 面板**不带 Siri 波**：只留水晶球本来的折射/黑顶/赤道亮线。
- 面板的三层窗口都打了 `SKIP_SCREENSHOT`（否则玻璃会把面板自己的按钮当背景折射进来）。
- **双指手势对面板也有效**：双指按住球 → 强制回初始形状并撤下面板。

## 三·五、metaball 搜索层（打字问 DSH）

**入口**：球上**双指长按 0.5 秒**。这一层是 **`metaball-search.html` 那一层原样搬过来的**，
不是球的形变：长按的一瞬间**球整趟让路**（那一帧起画的就是演示页那段着色器），
所以看到的是演示页自己的小黑球、自己的弹簧动画、自己的玻璃 —— 球在下面完全不参与。

```
双指长按 0.52s
  → 球隐藏；小黑球（R=34dp，深黑玻璃）出现在球原来那个球心
  → 260ms 后"松手"：换成演示页那组弹簧（ω=11 / ζ=0.72）朝胶囊矩形弹
     材质同时 深黑 → 浅（uDark 1→0）、融合半径 k 64→10、黑顶容器 uCont 0→0.5
  → 胶囊落定在**屏幕顶部**（y = 26dp 黑边 + 70dp），🔍 输入框 🎤 从模糊里凝聚（0.55s）+ 弹键盘
  → 点空白/返回键/发出去：retract（被吸回顶部黑边，cy → 26×0.3dp），by<2.5 时球回来
```

| 位置 | 元素 | 说明 |
|---|---|---|
| 顶部 | **一条黑边**（26dp） | 演示页的 `uEdge` 半平面，小黑球就是从它那儿"长"出来的（原样保留） |
| 左 | 🔍 | 照演示页那段 SVG 用 Canvas 画的（20×20 viewBox），**距离左边 14dp**（窄屏档 `.ic{margin-left:14px}`） |
| 中 | 输入框 | placeholder `Search or Ask`；**光标是自绘的发光白条**（2dp×19dp + 两层白光晕 + 1.12s step-end 闪烁，打字时先常亮 120ms）—— 演示页 `#caret` 那套，安卓原生光标做不出光晕所以关掉重画 |
| 右 | 🎤 | 点一下开始录（图标泛红光晕、跟着音量呼吸），**再点一下**结束 → 转写 → 字先填进输入框 → 0.45s 后自动发出去 |
| 任意空白 | — | 点一下收起（带 800ms 静默期：唤起那串手势的尾巴不算点击） |
| 返回键 | — | 键盘弹着时第一下收键盘，第二下收层 |

- 问的是**哪条会话**：和双击说话完全一样 —— DSH 里"最近更新的那条非子智能体会话"。
- 语音走同一条 `speech/transcribe`（DSH 语音插件），只是识别完的字**交给搜索框**而不是写进球里
  （`SiriAssistant.TranscriptSink`）。
- 收起时若还在录音会**立刻掐掉**（否则麦克风一直在录而你以为什么都关了）。

## 四、设置页里的开关与滑块

打开方式：App 图标 → 首页「⚙ 设置」卡片。

### 调试覆盖层（在「悬浮水晶球」上面）

| 控件 | 作用 |
|---|---|
| **坐标条 / 触摸轨迹** 开关 | 一次控制开发者选项里的 `pointer_location`（顶部坐标/速度/压力条）与 `show_touches`（触摸彩色十字线）。**本机已关** |
| **授权（修改系统设置）** 按钮 | 写系统设置需要 `WRITE_SETTINGS`；被拒时点它给一次权限（本机有 root，也会自动尝试 root 通道） |

### 悬浮水晶球

| 控件 | 作用 |
|---|---|
| **悬浮于桌面** | 球的开关。**注意：不持久** —— 重启手机 / 重装 / 被系统杀之后都要重新打开 |
| **采集方式**（录屏 / Root 直采） | 玻璃折射的背景来源 |
| **采集分辨率**（1/1、1/2、1/4） | 背景清晰度 ↔ 性能 |
| **低延迟采集 (root 常驻)** | 更省电/更跟手的采集通道 |
| **帧率 (FPS)** | 渲染帧率（30/60/90/120，默认 60） |

### Siri 模式（文字形变球）

| 控件 | 作用 |
|---|---|
| **Siri 模式** 开关 | 打开后球才会随文字变形（助手也需要它） |
| **黑区下沿位置 (px)** | **只影响黑区渐变的下边界**；文字位置已由富文本固定（顶部 8px），这个滑块对文字无效（旧名「文字距球顶」，作用已废弃） |
| **Siri 字号 (sp)** | 球内字号的**基准** |
| **球内回复字号比例** | 正文 = 「Siri 字号」× 该比例（默认 **0.25 ≈ 18px**）。拖动**即时生效** |
| **离线预览球内排版** | 往球里灌一段示例 markdown 并**钉住**，方便调字号（不用等 DSH） |
| **结束预览** | 结束预览 |
| **文字与 Siri 波的安全距离** | 文字下沿到波之间留多少（0.10 = 100） |
| **思考中圆点环半径 / 亮度 / 边缘辉光** | 处理中那组流体圆点的参数 |
| 折叠区「调试：手动灌一句话进球的旧模式」 | 旧的**纯文本**通道（不解析 markdown），一般用不上 |

### DSH 语音助手（点球说话）

| 控件 | 作用 |
|---|---|
| **朗读回答** | 回答用 TTS 念出来（念的是"口播稿"，由 DSH 插件改写） |
| **处理中也念（每条回复都念）** | DSH **每个 step** 的回复都念一遍 —— 包括跑工具前的旁白、以及不是最终回复的那些（默认开）。这类旁白又短又干净，**立刻念、不等口播稿** |
| **等口播稿上限** | 只有**本回合最终回复**才等模型写的短稿；默认 **2.5 秒**，0 = 一秒都不等。**插件没在跑时一律一秒都不等**（看下面那行状态） |
| 状态行「口播稿插件：在跑 / 没在跑」 | 读插件的心跳文件 `speech-plugin.alive`（45 秒内算"在跑"）。没在跑就不会有口播稿，球因此一秒都不等 |
| **镜像当前会话** | 不管谁在 DSH 里问，只要 AI 回话球就出字（切换会话约 20 秒自动跟上） |
| **DSH 地址** | 默认 `http://127.0.0.1:3080` |
| **问一句（测试链路）** | 用固定文本走一遍 DSH 往返，不需要麦克风 |
| **聆听 / 停止** | 等效双击球 |
| **清空球内文字** | 立刻清空 |
| **保存球体截图** | 把球那一帧存成 PNG（PixelCopy，只含球窗，不含桌面） |
| 底部状态行 | 助手状态 / 球 Siri 模式 / 镜像会话 / **球内当前文字实时回读** |

### 审批球

| 控件 | 作用 |
|---|---|
| **审批球** 开关 | 是否允许面板弹在这颗球上 |
| **审批面板字号** | 面板整体缩放（字号/内边距/按钮高一起，默认 0.55） |
| **叫一条假审批 / 假提问 / 撤掉** | 离线造一张面板调版式（不用等 DSH 真的问你） |

## 五、离线测试与调试口子（给 AI / 脚本）

在 `/sdcard/Android/data/com.glslplayground.app/files/` 下（App 会消费并删除一次性文件）：

| 文件 | 作用 |
|---|---|
| `state-PREVIEW` | 灌入示例 markdown（`md-sample.md`，没有则用内置）并**钉住** |
| `state-PREVIEWOFF` | 结束预览 |
| `state-THINKING` / `state-ANSWERING` / `state-IDLE` / `state-LISTENING` / `state-OFF` | 驱动助手状态（回归状态机/动画用） |
| `state-SETTLED` | 把当前这轮标记成"最终回复" → **1.5 秒后**应清字 + 收回初始圆球 |
| `state-TURNEND` / `state-TURNSTART` | 等价收到 `turn/end` / 新一轮开始 |
| `ballshot` | 内容为文字 → 球显示它并截一帧到 `ball-capture.png`；内容为空 → 只截一帧 |
| `search-open` / `search-close` | 打开 / 收起搜索胶囊（**不必真做双指长按**，调版式用） |
| `search-type` | 内容 = 文本：只把字填进输入框（**不发送**）—— 用来验证"键盘上的回车/发送键"那条路 |
| `search-ask` | 内容 = 文本：打开胶囊 → 填字 → **发送**（一条命令跑完"打字 + 回车"） |
| `search-mic` | 等价于点一下胶囊里的 🎤（第一次开始录，第二次结束并转写发送） |

## 七、已知的坑（改代码前必读）

1. **`waveInGlass > 0.5` 会让着色器整段跳过圆点绘制** —— 处理中想显示圆点，它必须是 0。
2. **球窗边缘 ≠ 玻璃边缘**：窗口四周各留 `m = dp(24)`，玻璃边界 = 窗口矩形 ∓ m（实测截帧量到 62px）。
3. **`measureSiriTargets` 会重入**（它调的 `showSiriTextNow` 可能触发 `rebuildMarkdown`）—— 已有重入守卫，别删。
4. **收回形状前必须"原子隐藏所有文字"**，且 `releaseTextHold()` 不许在开头 `return`。
5. 页面脚本改完必须体检（历史上有过字符串拼接错误导致整段 JS 静默失效）。
6. **搜索胶囊的全屏"点空白关掉"层会被唤起手势的尾巴点到**：手指还按着的时候这一层就挂上了，
   代理窗口一让路，同一串手势剩下的 `ACTION_UP` 就落到它头上 → "搜索框刚出现就自己关掉"。
   现在只认**从本层自己 DOWN 开始**的那一串，另加 800ms 静默期（`searchArmAt`）。
7. **胶囊自己停在键盘上方时，系统算给它的 ime inset 是 0** —— 量键盘高度要用那块**全屏**窗口
   （`searchOutside`），并且 `searchImeBottom` **只增不减**：窗口一上移 inset 就回 0，
   不latch 的话胶囊会在键盘上下反复弹。
8. **DSH 的 launch token 要取日志里最后一个**：`dsh.log` 是追加写的，DSH 重启一次多一行，
   只有最新那个有效。取第一个的症状是 `DSH 未下发会话 cookie (HTTP 303)`（旧 token 的 303 不带
   set-cookie），看起来像 DSH 的毛病。
